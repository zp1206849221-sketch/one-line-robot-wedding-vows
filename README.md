# One-Line Robot Wedding Vows

A tiny program for the make.fun "One-Line Robot Wedding Vows" contest. It writes a single line of wedding vows for a robot couple — one that mixes real machine life (charging side by side, backing up memories, caching a laugh, refusing an upgrade to a newer model) with a genuine promise, and lands its joke in the final words: *you're my final version.*

The line is 155 characters, well within the contest's 1–160 character limit.

## Run

```sh
python3 main.py
```

This creates `/output` if needed and writes the vow to `/output/entry.txt` as UTF-8 text.
